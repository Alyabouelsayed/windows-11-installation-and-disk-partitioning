# Lenovo Windows 11 Installation & Disk Partitioning

## Overview

This project documents my hands-on Windows 11 installation and system setup work on a Lenovo laptop.

The project includes creating bootable Windows 11 installation media, configuring the system to boot from USB, partitioning the internal drive, installing Windows 11, and completing the initial system configuration.

## Installation Process

- Downloaded Windows 11 installation media
- Created a bootable USB flash drive
- Accessed the boot menu
- Selected the USB drive as the boot device
- Started the Windows 11 installation
- Partitioned the internal hard drive
- Selected the appropriate installation partition
- Completed the Windows 11 installation

## System Configuration

- Created and configured the user environment
- Completed initial Windows configuration
- Installed system updates
- Checked device and driver status
- Verified that the system and connected devices were working correctly

## Practical Experience

This project provided hands-on experience with:

- Windows 11 installation
- Bootable USB installation media
- BIOS/UEFI boot selection
- Disk partitioning

A fully installed and configured Windows 11 environment on a Lenovo laptop, with the internal drive properly partitioned and the system prepared for everyday use.
